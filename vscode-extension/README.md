# Agent Bridge

一键启动 **Bridge** 和 **中继客户端**，让手机通过飞书远程操作这台机器上的 Claude Code。

## 使用

1. 安装插件（见下）。
2. 在设置里填 `agentBridge.relayAddress`（管理员提供，推荐 `https://relay.example.com:9010`，全程加密），或首次启动时按提示输入。写成 `主机:端口` 是明文连接，仅用于内网或测试。
3. 首次启动会弹出二维码面板，用飞书扫码并在手机上确认。校验码要与面板上的一致。
4. 之后每次打开 VS Code 会自动启动，状态栏左下角显示 Bridge 状态，点击打开菜单。

凭据保存在插件的存储目录里，重启后不会丢。

## 安装位置

- 本地 VS Code：安装后在本机运行。
- 连接容器、SSH 或 WSL：在已连接的窗口里安装，插件会装进远端并在那里运行。Bridge 需要访问 `claude` 命令和会话文件，所以必须跑在 Claude Code 所在的机器上。

安装：`Extensions: Install from VSIX...`，或命令行 `code --install-extension agent-bridge-0.1.0.vsix`。

## 多个窗口、多个容器

- **同一个环境里的多个窗口**（比如本机直装的 VS Code 开了好几个窗口）共用同一份凭据，只托管一个 Bridge，不用多次扫码，手机上是同一台电脑、会话按窗口分组。
- **连接不同的远程环境**（多个容器、SSH 主机、WSL）时，每个环境各存一份凭据，对手机来说是不同的电脑：在每个环境里各扫一次码即可，互不顶掉，手机侧栏里可以切换。
- 手机上看到的电脑名是 `名称@当前文件夹名`。容器的主机名是一串随机字符，**有多窗口需求时强烈建议在设置里填写 `agentBridge.computerName`**，手机上才分得清。名字只在绑定时上报一次，改名后用“重新绑定手机”更新。

## 要求

- Linux 或 macOS（Windows 请用 WSL / Dev Containers）。
- 不需要安装 Python 或 Node：Bridge 和中继客户端运行在 VS Code 自带的 Node 上。
- 已安装并登录 `claude` 命令。

## 命令

`Agent Bridge:` 启动 / 停止 / 重启 / 重新绑定手机 / 显示绑定二维码 / 查看日志 / 检查更新。

## 说明

- 状态栏的“运行中”表示 Bridge 和客户端进程已启动，无法确认与中继的连接是否正常，连接问题请看日志。
- 多个窗口同时打开时，第一个窗口托管 Bridge，其他窗口显示“已接入主窗口”：它们的文件夹会登记到同一个 Bridge，手机上能看到所有窗口的会话（按文件夹分组）。主窗口关闭后，其余窗口约 30 秒内会有一个自动接手。
- 同一文件夹开两个窗口时，手机上无法区分。

## 更新

管理员通知有新版本后，点状态栏左下角的 Agent Bridge，选“检查更新”（或命令面板里的 `Agent Bridge: 检查更新`）。有新版本会提示，点“立即更新”，装完按提示重新加载窗口即可，不需要重新扫码。插件不会自己联网检查更新。

检查更新需要中继地址是 `https://` 形式。新版本的安装包带有签名，插件只会安装签名校验通过的版本。
